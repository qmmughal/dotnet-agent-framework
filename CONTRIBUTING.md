# Contributing

Thank you for your interest in contributing to the .NET Multi-Agent Orchestration Framework! 

## How to Contribute

1. **Fork the Repository**: Create a fork of the repository to your own GitHub account.
2. **Create a Branch**: Create a feature branch for your changes (`git checkout -b feature/AmazingFeature`).
3. **Commit your Changes**: Write clear, descriptive commit messages.
4. **Push to the Branch**: Push your changes to your fork (`git push origin feature/AmazingFeature`).
5. **Open a Pull Request**: Submit a Pull Request from your fork to the `main` branch of this repository.

## Development Setup
- Install the .NET 8.0 SDK.
- Open `AgentFramework.slnx` in Visual Studio, Rider, or VS Code.
- Run `dotnet build` to ensure everything compiles.

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) to keep our community approachable and respectable.
